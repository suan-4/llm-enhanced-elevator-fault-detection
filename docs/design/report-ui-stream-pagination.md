# 报告侧栏流式显示与人工确认翻页

日期：2026-10-31

## 1. 打字机流式显示

原实现：StreamingOverlay 全局遮罩。

现改为：

- 显示在录入页「检测项目填写」内容最底部；
- 生成开始时出现；
- 自动滚动到页面底部；
- 流式文字继续追加时保持贴底；
- 使用 Markdown 渲染；
- 底部留出操作条空间，避免被固定操作栏遮住。

## 2. 人工确认翻页

/kg-confirm 原实现：所有不符合项纵向排列。

现改为：

- 每个不符合项一页；
- 顶部显示当前页 / 总页数；
- 屏幕左右固定单图标按钮：
  - 左：‹ 上一项
  - 右：› 下一项
- 首/尾页对应按钮禁用；
- 翻页时自动回到页面顶部；
- AI 推荐、批量推荐、无合适候选、审计逻辑保持。

## 3. push.bat 壁纸

push.bat 部署时设置：

    ELEVATOR_SKIP_WALLPAPER=1

harden_kiosk.sh 在该变量为 1 时：

- 不生成、不修改壁纸；
- 保留现场原壁纸；
- 仍关闭桌面图标、Dock 自动隐藏等加固项。

手动执行 install_kiosk.sh 时不带该变量，仍按原逻辑设置纯色壁纸。
