# 离线触摸键盘

用户已确认应用内键盘、手写、语音完全离线，要求沿用常见平板键盘习惯并直接实施。

- 板端文字输入聚焦弹出底部停靠面板：候选栏、QWERTY、中文/英文、123、符号、删除、空格、下一项、收起。数字字段显示数字布局；按钮、选择框和只读内容不弹。桌面保留物理键盘，提供手动开启入口。
- 手写单字多笔画输入，离线候选字点选上屏，撤销一笔、重写、删除；自带本地识别代码和字形库，保留许可。
- 拼音复用已有 Fcitx5 本地引擎，通过独立 D-Bus 上下文返回词语候选，不更换系统输入法。上下文不加入真实显示器焦点组。
- 语音按开始/停止录入，单次最多30秒；本地 SenseVoice/sherpa-onnx 转写，结果先展示、可修改，明确点击填入当前字段。关闭、切换字段和离开页面取消录音；口令字段禁用手写/语音。临时音频结束后删除，不存报告、不上传。
- 保留光标位置、选区、中文与emoji删除边界、maxlength及数字限制；键盘不盖住当前输入，不触发表单提交，不抢输入框焦点。
- WebKit原生焦点桥在检测到新键盘已接管时关闭GNOME软键盘；旧页面保留原桥，避免双键盘。保留启动页与登录页原有样式。
- 生成/计分逻辑不变。ASR能力缺失显示可理解原因；拼音、手写缺失不得假造候选。
- 复用现有生成与部署流程；候选版先验收，再备份并更新板端。已有方案、草稿不覆盖。

验收：600×960与960×600及实机双方向；拼音“zhidongqi”候选制动器；手写“十”候选；文本中间插入/替换选区/emoji删除/数字；切换字段无晚到的识别结果串入；录音取消、超时、无声、模型缺失；离线样本真实转写。实测耗时及麦克风状态如实报告。
